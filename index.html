Syphon-Ausgang (TouchDesigner, Resolume, MadMapper …)

Browser können Syphon nicht direkt senden. Deshalb schickt ArtLoop das Bild an ein kleines Hilfsprogramm auf deinem Mac, das es als Syphon-Quelle „ArtLoop“ bereitstellt.
  1. (artloop_syphon.py – enthält ArtLoop gleich mit)
  2. Einmalig im Terminal: python3 -m pip install "syphon-python[numpy]"
    Braucht Python 3.10+. Meldet macOS ein älteres Python, aktuelles Python von python.org installieren.
  3. Starten: python3 ~/Downloads/artloop_syphon.py – Terminal-Fenster offen lassen.
  4. Im Browser http://127.0.0.1:8765 öffnen – ArtLoop kommt dann direkt vom Hilfsprogramm, die Verbindung klappt so am zuverlässigsten.
  5. Dort Syphon › Senden starten.
  6. In TouchDesigner: Syphon Spout In TOP → Sender Name ArtLoop.
